# Matriz de rastreabilidade

Liga cada módulo, endpoint, fluxo e regra do backend ao código que o implementa, à documentação que o descreve e aos testes que
o validam (issue #160). Levantada sobre `develop` em `20a450d` e mantida no mesmo PR de qualquer mudança de contrato.

**Como a matriz é verificada.** `RastreabilidadeTests` (suíte sem dependências externas) falha se:

- um endpoint da API (verbo + rota, lido por reflexão dos controllers) não aparecer na tabela 1;
- a tabela 1 citar um endpoint que não existe mais;
- uma classe de teste citada aqui não existir no projeto de testes.

**Legenda das colunas de teste.**

- **Sem dependências externas:** suíte que roda sem SQL Server, Docker ou rede (job `build-and-test`). Inclui testes unitários puros
  e testes de componente em processo (`WebApplicationFactory` com EF InMemory, ViaCEP simulado por `ViaCepFalso`). É a base da
  [cobertura unitária](test-coverage.md#unitária-x-combinada).
- **SQL Server / processo real:** `Category=RequiresSqlServer` (job `sqlserver-integration`): SQL Server 2022 real e descartável,
  migrations completas, triggers, `SESSION_CONTEXT`, locks, identidades SQL do bootstrap e, nos `ApiProcess*`, a API no próprio
  processo (Kestrel) com a identidade de runtime de menor privilégio.
- **E2E:** execução da aplicação publicada com os fluxos de ponta a ponta; as evidências de cada rodada ficam no PR da issue
  correspondente (a da #160 está no PR #175).

`AuthorizationTests` aparece em todos os endpoints porque verifica, rota por rota e cargo por cargo, a matriz `401`/`403`/permitido
de [`authentication-security.md`](authentication-security.md#perfis-e-matriz-de-acesso-31-127).

|---|---|
| **Auditoria HTTP, caminho sem rota casada (404).** O sanitizador mantém GUIDs e inteiros de até 9 dígitos em segmentos que não são de uma rota conhecida ([auditoria-http.md](auditoria-http.md#política-de-sanitização), item 8). Um CEP (8 dígitos) digitado numa rota inexistente, como `/api/Cep2/01001000`, é gravado, enquanto o README afirma que endereço nunca vai para o caminho. Nas rotas reais, `{cep}` vira `[omitido]`. | ⚠️ decisão do mantenedor: reduzir o tamanho aceito (pode tirar números legítimos do registro) ou ajustar o texto. Não foi alterado na #160. |
